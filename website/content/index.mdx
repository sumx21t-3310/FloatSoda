## 最小構成のコード

SteamVR のダッシュボードに 100×100 の青い箱を出すオーバーレイです。`samples/FloatSoda.Samples.GettingStarted` の `Program.cs` そのもので、ビルドのたびにここへ読み込まれます。

## 誰のためのフレームワークか

3 タイプの作り手を想定しています。自分に近いものから読み始めてください。詳しくは [Target Users](/targetusers/) にあります。

<CardGrid>
  <Card title="AI と一緒に自分用のツールを作りたい VRChatter" icon="rocket">
    コードが書けなくても構いません。AI にコードを書いてもらう「バイブコーディング」で完結できることが設計目標です。

    読む順: [GettingStarted](/gettingstarted/) のサンプルを動かし、あとは AI に「これを改造して◯◯を作って」と頼む。AI には下の `llms-full.txt` を渡してください。
  </Card>
  <Card title="Booth でオーバーレイ作品を売りたいクリエイター" icon="pencil">
    Unity でワールドやギミックを作れるなら十分です。新しく覚えるのは「宣言的 UI」という考え方だけ。シーンもプレハブも `.meta` もありません。

    読む順: [GettingStarted](/gettingstarted/) → [WidgetSystem](/widgetsystem/)
  </Card>
  <Card title="uGUI を使いたくないエンジニア" icon="laptop">
    UI が 100% C# コードです。diff が読め、PR レビューができ、grep が効きます。Flutter の三ツリーモデルを .NET 上に実装しています。

    読む順: [Architecture](/architecture/) → [APIDesign](/apidesign/)
  </Card>
</CardGrid>
