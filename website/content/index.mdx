## オーバーレイを1枚作るだけで、こんなにコードを書くの?

SteamVR のオーバーレイは、VR の中に浮かぶ 2D のパネルです。自分用のオーバーレイを作るときの主な作り方は、これまで次の3つでした。

- Unity で作る。オーバーレイ1枚のために、ゲームエンジンを丸ごと動かす
- C++ で OpenVR を直接呼ぶ。並べ方の計算も描画も、自分で書く
- Qt などのデスクトップ向けの UI を、自分で OpenVR につなぐ

時計を1つ浮かべたいだけでも、この3つのどれかから始めることになります。

## 欲しいのは画面のレイアウト

FloatSoda では、「状態がこうなら、画面はこう見える」を C# のコードで書きます。並べ方の計算、描画、SteamVR への受け渡し、状態が変わったときの描き直しは、FloatSoda が受け持ちます。書き方は Flutter と同じ形で、Unity のシーンやプレハブの代わりに、画面をコードで組み立てます。

次のコードは、SteamVR のダッシュボードに出す、最小のオーバーレイです。`samples/Showcase/FloatSoda.Samples.GettingStarted` の `Program.cs` そのもので、ビルドのたびにここへ読み込まれます。

{/* Program.cs は BOM 付き UTF-8 なので、先頭の BOM(U+FEFF)を落としてから表示する */}

## コードだから、全部読めるし探しやすい

FloatSoda の UI はすべて C# のコードで、シーンもプレハブも持ちません。画面がどこで組まれているかは、コードを検索すれば見つかります。変更は diff で追え、コードを AI に書かせることもできます。このサイトは、コーディングエージェントがそのまま読めるように作ってあります。
