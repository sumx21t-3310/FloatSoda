# OverflowBox 確認手順

同じ大きさの枠の中で、制約の受け渡しと自身の寸法の決め方を4通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.OverflowBox -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が4つ横に並ぶ。
2. `親より大きい制約` の枠で、水色の帯(幅 `190`・高さ `40`)が上下中央にあり、**枠の左右の端を越えて枠の外(ページの紺色の背景の上)まで描かれている**。
3. `Fit = Max(既定)` の枠で、茶色が枠いっぱい(`150 x 150`)に広がり、その中央に朱色の四角(`60 x 60`)がある。
4. `Fit = DeferToChild` の枠で、茶色が見えず、朱色の四角(`60 x 60`)だけが枠の背景色(濃いグレー)の中央にある(自身が子と同じ寸法まで縮み、茶色が子の背後に隠れている)。
5. `SizedOverflowBox` の枠で、茶色の四角(`80 x 80`)の中央に黄色の帯(幅 `120`・高さ `40`)があり、**黄色が茶色の左右の端を越えて突き出している**。
6. 4つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.OverflowBox
```

1. SteamVR ダッシュボードに `OverflowBox` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(4枠のはみ出しと自身の範囲)。
