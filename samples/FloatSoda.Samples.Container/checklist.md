# Container 確認手順

同じ大きさの枠の中で、Container が合成するプロパティの効果を5通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Container -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が5つ横に並ぶ。
2. `Color + 寸法` の枠で、水色の四角(`96 x 96`)が枠の中央にあり、枠いっぱい(`150 x 150`)には広がっていない。
3. `Decoration` の枠で、朱色の角丸四角(`110 x 110`、角丸半径 `16`)の外周に黄色のボーダー(太さ `4`)が四辺とも見える。
4. `Padding` の枠で、黄色の角丸四角(`110 x 110`)の内側に各辺 `16` の余白が見え、子の水色の四角が装飾より小さく、装飾の角丸に重ならない。
5. `Alignment` の枠で、朱色の四角(`40 x 40`)が枠の右下隅に接しており、他の位置には何も描画されない。
6. `Transform` の枠で、水色の四角(`80 x 80`)が中心を軸に時計回りへ22.5度傾いている。
7. 5つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Container
```

1. SteamVR ダッシュボードに `Container` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(5枠の並びと各プロパティの効果)。
