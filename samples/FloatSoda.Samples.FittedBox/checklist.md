# FittedBox 確認手順

同じ大きさ(`150 x 100`)の枠の中で、`120 x 64` の旗(右下に朱色の目印)の収め方を5通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.FittedBox -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの横長の枠が5つ並ぶ。
2. `Contain(既定)` の枠で、旗が幅いっぱい(`150 x 80`)に拡大され、上下に枠の背景色が同じ幅で見える。朱色の目印は正方形のまま。
3. `Fill` の枠で、旗が枠全体(`150 x 100`)に引き伸ばされ、**朱色の目印が縦長に歪んでいる**。
4. `None` の枠で、旗が自然な大きさ(`120 x 64`)のまま中央にあり、四辺に枠の背景色が見える。朱色の目印は2番より小さい。
5. `Cover + HardEdge` の枠で、旗が枠の高さ全体を覆うまで拡大され、**左右のはみ出しが枠の端で切り取られている**。枠の背景色は見えない。
6. `Cover(クリップなし)` の枠で、5番と同じ拡大率のまま、**はみ出した部分が枠の外(ページの紺色の背景の上)まで描かれている**。
7. 2番と5番で朱色の目印が正方形のままである(`Contain` / `Cover` は縦横比を維持する)。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.FittedBox
```

1. SteamVR ダッシュボードに `FittedBox` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(5枠の拡大縮小とクリップの有無)。
