# DecoratedBox 確認手順

同じ大きさの枠の中で、装飾の組み合わせと前面描画を4通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.DecoratedBox -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が4つ横に並ぶ。
2. `背景色と角丸` の枠で、水色の四角(`110 x 110`)の四隅が半径 `24` で丸まっている。
3. `ボーダー` の枠で、朱色の四角の四辺に黄色の枠線(太さ `6`)が同じ太さで引かれている。角は直角のまま。
4. `角丸ボーダー` の枠で、水色の枠線(太さ `4`)が角丸(半径 `24`)に沿って引かれており、角の丸みの部分でも枠線が途切れていない。
5. `Foreground` の枠で、水色の四角の上に半透明の黄がかぶさり、**全体が黄緑がかった色に見える**(前面に描かれた装飾を透かして下の水色が見えている)。
6. 4つの枠がすべて同じ大きさ(`150 x 150`)で、装飾はどれも `110 x 110` の範囲に収まっている。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.DecoratedBox
```

1. SteamVR ダッシュボードに `DecoratedBox` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(4枠の装飾)。
3. `Foreground` の半透明の重なりが、オーバーレイの透過背景の上でも破綻していない。
