# GestureDetector 確認手順

タップの成立条件と、ドラッグによる追従を実際にポインターで操作して確認する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上でマウス操作して判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.GestureDetector -- --desktop
```

1. デスクトップウィンドウが開き、水色のタップボタン(「タップ 0 回」)と、朱色の箱が中央にあるフィールドが表示される。
2. タップボタンをクリックすると、離した時点で表示が「タップ 1 回」になる(押しただけでは増えない)。
3. ボタンの文字の無い部分をクリックしても回数が増える(`Opaque` で領域全体が反応する)。
4. 朱色の箱をドラッグすると、箱がポインターへ追従して動き、ドラッグ中は黄色に変わる。下の「箱の位置」の数値も追従する。
5. ドラッグを離すと箱は朱色へ戻り、「ドラッグ中: いいえ」になる。
6. 箱をフィールドの端へ向けてドラッグし続けても、箱はフィールドの外へ出ない(座標がクランプされる)。
7. 箱を押してすぐ離すとタップ回数は増えず、箱も動かない(タップとドラッグの判定が混線しない)。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.GestureDetector
```

1. SteamVR ダッシュボードに `GestureDetector` タブが現れ、開くとオーバーレイが表示される。
2. コントローラーのレーザーとトリガーで、2番と4番と同じ結果になる(タップが成立し、箱がレーザーへ追従する)。
3. トリガーを引いたままレーザーをオーバーレイの外へ出したとき、箱が飛んだり押しっぱなしのまま固まったりしない。
