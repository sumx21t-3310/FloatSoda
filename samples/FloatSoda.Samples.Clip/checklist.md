# Clip 確認手順

同じ「はみ出した子」を、切り抜き無し・矩形・角丸・楕円・HardEdge の5通りで比較する。

子は `190 x 110` の水色の矩形で、枠は `150 x 150`。左右に 20px ずつはみ出す。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Clip -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が5つ横に並ぶ。
2. `切り抜き無し` の枠で、水色の矩形が**枠の左右からはみ出して見えている**。
3. `ClipRect` の枠で、はみ出しが消え、水色が枠の幅ちょうどで切れている。
4. `ClipRoundRect` の枠で、水色の**四隅が丸く**切り取られている。丸みの半径は目測で 28px。
5. `ClipOval` の枠で、水色が**楕円形**に切り取られている。枠が正方形なので円に近い。
6. `HardEdge` の枠で、`ClipOval` と同じ楕円だが、**曲線の縁がギザギザ**している(アンチエイリアス無し)。
7. 4番と5番の曲線の縁が滑らかで、6番と明確に見分けられる。
8. 5つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Clip
```

1. SteamVR ダッシュボードに `Clip` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する。
3. アンチエイリアスの有無(4・5番 対 6番)が VR 内でも判別できる。オーバーレイの再サンプリングで差が潰れていない。
4. 切り抜いた領域の外側が透明ではなく、下地のグレーが見えている。
