# SizedBox 確認手順

寸法の固定、余白としての使い方、片方だけの指定を比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.SizedBox -- --desktop
```

1. デスクトップウィンドウが開き、上段に3つの矩形が横に並ぶ。
2. 3つの矩形の**高さが等しく**、幅だけが `200` / `120` / `60` と異なる。
3. 矩形どうしの間隔が均等で、目測で約 40px ある(子を持たない `SizedBox` が効いている)。
4. 下段に、幅がウィンドウの余白いっぱいまで伸びたグレーの帯がある。
5. その帯の高さが上段の矩形より低い(`Height = 70` のみ指定し、幅は親の制約に従っている)。
6. 帯の中央にラベルが表示されている。
7. 上段と下段の間に、目測で約 40px の縦の間隔がある。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.SizedBox
```

1. SteamVR ダッシュボードに `Sized Box` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する。
3. 幅を親に委ねた帯が、オーバーレイの幅に対して正しく伸びている(途中で切れていない)。
