# AspectRatio 確認手順

同じ大きさの枠の中で、比率ごとの寸法の決まり方と tight 制約の影響を4通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.AspectRatio -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が4つ横に並ぶ。
2. `16 : 9` の枠で、水色の横長の四角が枠の幅いっぱい(`150`)で高さ約 `84` になっており、上下中央にある。
3. `3 : 4` の枠で、朱色の縦長の四角が枠の高さいっぱい(`150`)で幅約 `113` になっており、左右中央にある(幅 150 だと高さ 200 が要るため、高さ側が上限になる)。
4. `1 : 2` の枠で、黄色の縦長の四角が高さ `150`・幅 `75` になっており、左右中央にある。
5. `tight では効かない` の枠が、比率 16:9 の指定にもかかわらず水色で枠いっぱい(`150 x 150` の正方形)に塗られている。
6. 4つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.AspectRatio
```

1. SteamVR ダッシュボードに `AspectRatio` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(4枠の四角の縦横比)。
