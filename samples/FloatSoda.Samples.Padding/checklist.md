# Padding 確認手順

同じ大きさの枠の中で、EdgeInsets の作り方ごとの余白の付き方と収縮を4通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Padding -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が4つ横に並ぶ。
2. `All(16)` の枠で、水色の塗りの周囲に濃いグレーの額縁が四辺とも同じ幅(`16`)で見える。
3. `Symmetric(12, 36)` の枠で、朱色の塗りの左右の額縁(`36`)が上下の額縁(`12`)より明らかに広い。
4. `Left だけ 48` の枠で、黄色の塗りの左側だけに広い額縁(`48`)があり、上下と右は枠に接している。
5. `子に合わせて縮む` の枠で、水色の四角(`48 x 48`)の周囲に**茶色の下地が各辺 `16` だけ見えており、その外側は枠の背景色(濃いグレー)のまま**である。
   茶色の領域が `Padding` 自身の範囲で、`80 x 80` に縮んでいる。枠いっぱい(`150 x 150`)には広がっていない。
6. 4つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Padding
```

1. SteamVR ダッシュボードに `Padding` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(4枠の並びと各余白の付き方)。
