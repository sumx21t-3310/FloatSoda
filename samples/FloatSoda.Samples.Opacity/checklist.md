# Opacity 確認手順

同じ大きさの枠の中で、グループ合成と 0.0 の領域保持を3通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Opacity -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が3つ横に並ぶ。
2. `1.0(既定)` の枠で、水色と朱色の四角(各 `70 x 70`)が斜めに重なり、重なり部分は手前の朱色で完全に覆われている。
3. `0.5` の枠で、2つの四角が両方とも薄くなり、背後の枠の背景色が透けている。
4. `0.5` の枠の**重なり部分が、朱色の単独部分と同じ濃さ**である(グループ単位の合成。重なりだけが濃く見えたら不正)。
5. `0.0 でも領域は残る` の枠で、水色と黄色の四角の間に、**四角1つぶんと間隔ぶんの空白**が空いている(朱色の四角が透明のまま領域を占有している)。
6. 3つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Opacity
```

1. SteamVR ダッシュボードに `Opacity` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(3枠の濃さと空白)。
3. `0.5` の半透明が、オーバーレイの透過背景の上でも破綻していない。
