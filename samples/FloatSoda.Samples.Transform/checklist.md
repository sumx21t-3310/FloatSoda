# Transform 確認手順

同じ大きさの枠の中で、回転の原点・縮小・平行移動を4通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Transform -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が4つ横に並ぶ。
2. `回転(原点は左上)` の枠で、水色の四角(`90 x 90`)が 15° 傾いており、**左上の角が回転前の位置(枠の中央に置いた場合の左上)から動いていない**。
3. `回転(中心が原点)` の枠で、朱色の四角が同じ 15° 傾きのまま、**枠の中央にとどまっている**(中心を軸にその場で回っている)。
4. 2番と3番で四角の位置が異なる(原点の違いだけで、行列は同じ)。
5. `縮小 0.6` の枠で、黄色の四角が `54 x 54`(0.6倍)で枠の中央にある。
6. `平行移動(描画のみ)` の枠で、水色の四角が中央から右下(`+40, +28`)へずれ、**右端が枠の端を越えて枠の外まで描かれている**(レイアウト領域は動いていない)。
7. 4つの枠がすべて同じ大きさ(`150 x 150`)である。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Transform
```

1. SteamVR ダッシュボードに `Transform` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(4枠の傾き・縮小・ずれ)。
