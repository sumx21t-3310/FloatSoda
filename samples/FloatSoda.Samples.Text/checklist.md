# Text 確認手順

同じ文字列表示を、既定書式・サイズ指定・太字・斜体・`RichText` の5通りで縦に並べて比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Text -- --desktop
```

1. デスクトップウィンドウが開き、5行すべてのテキストが表示される。
2. 1行目(既定書式)が、他の行より小さい既定サイズで描画されている。
3. 2行目が `FontSize 36` として、1行目より明確に大きい。
4. 3行目が太字として描画され、同じサイズの4行目より線が太い。
5. 4行目が斜体として、右に傾いて描画されている。
6. 5行目(`RichText`)が、`Text` で書いた行と同じ品質で描画されている。
7. 日本語が文字化けせず、豆腐(□)にならずに表示される。
8. 各行の色が指定どおり異なっている(白 / 水色 / 朱色 / 灰色)。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Text
```

1. SteamVR ダッシュボードに `Text` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する。
3. 最小の行(既定書式)が VR 内で潰れずに読める(`Dpm = 1000` での可読性確認)。
4. 斜体と太字の差が VR 内でも判別できる。
