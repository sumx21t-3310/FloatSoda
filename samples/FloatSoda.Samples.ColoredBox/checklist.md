# ColoredBox 確認手順

全面の背景塗り、子のサイズに従った塗り、入れ子の重なりを比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.ColoredBox -- --desktop
```

1. デスクトップウィンドウが開き、ウィンドウ全面が濃紺で塗られている。
2. 左側に水色の矩形が1つ表示され、`200 x 160` の大きさである(子のサイズに従っている)。
3. 中央に緑の矩形が1つ表示され、`120 x 160` の大きさである(子を持たない `ColoredBox` が親の制約いっぱいに広がっている)。
4. 右側に濃いグレーの矩形があり、その内側に朱色の矩形が表示されている。
5. 朱色の矩形の四辺に、均等な幅のグレーの縁が残っている(`Padding` の 28 分)。
6. 朱色が完全にグレーの上に描かれており、下の色が透けていない。
7. 各矩形の間に、塗られていない濃紺の間隔がある。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.ColoredBox
```

1. SteamVR ダッシュボードに `Colored Box` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する。
3. 色が指定どおりに見える(オーバーレイ合成で色が転んでいない)。
4. 矩形の縁がにじまず、はっきりした境界として見える。
