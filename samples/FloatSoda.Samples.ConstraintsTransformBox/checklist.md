# ConstraintsTransformBox 確認手順

同じ大きさの枠の中で、制約の取り除き方と軸の維持・クリップ・カスタム変換を4通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.ConstraintsTransformBox -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が4つ横に並ぶ。
2. `幅の制約は残す` の枠で、朱色の帯が枠の幅ちょうど(`150`)で止まっており、はみ出していない。
3. `HardEdge でクリップ` の枠で、黄色の帯が枠の左右の端で切り取られており、枠の外には描かれていない。
4. `カスタム変換` の枠で、水色の四角が `100 x 100` で中央にある。幅・高さ `220` の要求が変換後の最大値 `100` で止まっている。
5. `自然な大きさ` の枠で、水色の帯(幅 `220`)が**枠の左右の端を越えて、枠の外(ページの紺色の背景の上)まで描かれている**。
6. 2番・3番・5番の帯は同じ子(幅 `220`・高さ `40`)であり、違いは制約変換とクリップ指定だけである(コードで確認)。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.ConstraintsTransformBox
```

1. SteamVR ダッシュボードに `ConstraintsTransformBox` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(4枠の帯の幅・クリップ・はみ出し)。
