# Wrap 確認手順

幅360の枠の中で、折り返しと揃え方を3通り比較する。

## デスクトップ(`--desktop`)

HMD を接続し SteamVR を起動した状態で実行する。被る必要はなく、モニタ上で判定する。

```powershell
dotnet run --project samples/FloatSoda.Samples.Wrap -- --desktop
```

1. デスクトップウィンドウが開き、ラベル付きの枠が3つ縦に並ぶ。
2. `折り返しと間隔` の枠で、8個のチップが3つの run に分かれている(1行目3個、2行目3個、3行目2個)。
   どの run も枠の幅(`360`)を超えていない。
3. 同じ枠で、チップ同士の横の間隔と run 同士の縦の間隔がどちらも `8` で揃っている。
4. 同じ枠で、各 run は左端から始まり、右側に余りが残っている(`Alignment` の既定は `Start`)。
5. `Alignment.Center` の枠は2番と同じ折り返しのまま、**各 run が左右中央に寄っており、余りが左右へ均等に分かれている**。
6. `CrossAxisAlignment.Center` の枠で、1行目の高さ違いの四角(`32` / `48` / `64` / `32`)が**上下中央で揃っている**。
   一番高い黄色(`64`)の上下に、低い四角の余白が均等に見える。
7. 同じ枠で、5個目の四角が2行目へ折り返されている。

## ダッシュボード(HMD を被って判定)

```powershell
dotnet run --project samples/FloatSoda.Samples.Wrap
```

1. SteamVR ダッシュボードに `Wrap` タブが現れ、開くとオーバーレイが表示される。
2. 表示内容がデスクトップ実行時と一致する(3枠の折り返しと揃え方)。
